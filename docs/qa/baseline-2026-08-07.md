- `godot/scripts/**/*.gd` 与 `godot/scenes/*.tscn` 的核心方法、信号、模块接线基本符合 `godot/docs/ARCHITECTURE.md`。

- 已发现缺陷集中在弹道/命中完整性、友军视觉区分、热路径分配与声音映射，详见缺陷清单。

### Three.js 原型契约一致性

- `src/**/*.js` 的构造签名、关键方法、事件名与 `docs/ARCHITECTURE.md` 基本一致。
- `ProjectileSystem.spawnRocket/spawnGrenade` 存在，但没有武器输入或游戏循环调用；`game:wave` 无发送方。
- 最大缺陷：地形高度场未进入 `PhysicsWorld` 射线碰撞，hitscan、投掷物与 AI 视线均无法与地形正确交互。

## 4. 缺陷清单

### P0（阻断，0 项）

无。

### P1（严重，4 项）

**P1-1 Web 弹道与 AI 视线无法命中地形**
- 文件：`src/gameplay/Projectiles.js:42`、`src/core/Physics.js:70`、`src/render/Terrain.js:87`
- 问题：`PhysicsWorld.raycast` 只检测 `boxes` 与 `spheres`，`TerrainSystem` 只生成了网格和高度函数，未向物理世界注册地形；因此射击地面、山体会直接穿地，敌人视线也不会被山体遮挡。
- 预期结果：子弹、火箭、手雷与 AI 视线必须与地形高度场发生碰撞。
- 修复建议：在 `PhysicsWorld` 注入 terrain 引用，实现射线与高度场的步进求交；或为地形生成简化的分层碰撞盒。

**P1-2 Web 贴脸目标被近点忽略逻辑误跳过**
- 文件：`src/gameplay/Projectiles.js:37`
- 问题：`ignoreNearOrigin` 会忽略射线上所有中心距枪口小于 `radius + 0.2` 的球体，不只排除射手自身；贴脸敌人（约 0.7 米内）会被子弹穿过。
- 预期结果：只忽略射手自身碰撞体，近身敌人应可被命中。
- 修复建议：把忽略条件改为仅当 `candidate.object.userData.entity === shooter` 时忽略。

**P1-3 Web 手雷地面反弹高度写死**
- 文件：`src/gameplay/Projectiles.js:228`
- 问题：手雷在 `y < 0.45` 时按固定地面反弹，不读取 `TerrainSystem.heightAt`；高处会埋入地下，低处会悬空。
- 预期结果：手雷应在地形表面反弹。
- 修复建议：反弹前采样 `terrain.heightAt(x, z)`，或沿下落方向对地形高度场做射线检测。

**P1-4 火箭/手雷弹种未接入武器与输入**
- 文件：`godot/scripts/gameplay/weapons.gd:11`、`godot/scripts/gameplay/projectiles.gd:15`、`src/gameplay/Weapons.js:9`、`src/core/Game.js:152`
- 问题：架构契约明确包含“子弹、火箭、手雷”，但 Godot 只有 3 种 hitscan 枪械，无火箭/手雷；Web 版虽有 `spawnRocket/spawnGrenade` 方法，却没有弹种定义、输入键位和游戏循环调用。
- 预期结果：两种版本都应有可发射的火箭/手雷及对应爆炸伤害链路。
- 修复建议：增加火箭/手雷弹种与切换键或备用开火方式，接入 `explosion:detonated` 的范围伤害。

### P2（一般，9 项）

**P2-1 Web 波次事件无发送方**
- 文件：`src/gameplay/Enemies.js:55`、`src/ui/HUD.js:329`
- 问题：`spawnWave()` 只递增 `wave`，从未 emit `game:wave`；HUD 波次横幅与波次音频永远不会触发。
- 预期结果：每次生成波次后发送 `game:wave { wave }`。
- 修复建议：在 `spawnWave` 与 `spawnTeams` 完成后 emit `game:wave`。

**P2-2 Web 玩家受伤时误显示命中准星反馈**
- 文件：`src/ui/HUD.js:334`、`src/ui/HUD.js:474`
- 问题：`damage:target` 对玩家伤害的 `target` 是字符串 `'player'`，而 `#isPlayerTarget` 未识别该字符串，玩家受伤时也会播放命中标记。
- 预期结果：只有命中敌人时显示命中标记，玩家受伤时不显示。
- 修复建议：在 `#isPlayerTarget` 中直接判断 `payload.target === 'player'` 或实体对象。

**P2-3 Web 每发子弹热路径分配几何与材质**
- 文件：`src/gameplay/Projectiles.js:273`、`src/core/Physics.js:70`
- 问题：每次 hitscan 都新建并销毁 `BufferGeometry`、`LineBasicMaterial`、`CylinderGeometry`、`MeshBasicMaterial`；`raycast` 每次也新建 `Ray/Box3/Sphere`。连续自动射击会产生明显 GC 压力。
- 预期结果：高频弹道特效与射线查询应复用对象或使用池。
- 修复建议：tracer/弹孔使用对象池或 InstancedMesh；`Physics.raycast` 使用模块级临时对象。

**P2-4 Godot 敌方每枪执行两次物理射线**
- 文件：`godot/scripts/ai/enemy.gd:414`、`godot/scripts/main.gd:202`
- 问题：`_fire_weapon` 先 emit `enemy_fired` 让 `main.gd` 再射线检测玩家，随后 `_apply_shot` 又做一次全量射线检测敌方。
- 预期结果：同一发子弹应只执行一次命中结算。
- 修复建议：统一由一条射线完成玩家/敌人命中结算，或让 `enemy_fired` 携带命中结果。

**P2-5 Godot 每帧构造 HUD 状态字典与数组**
- 文件：`godot/scripts/main.gd:58`、`godot/scripts/gameplay/capture_zones.gd:69`
- 问题：`_process` 每帧调用 `get_state()` 与 `get_control_state()`，每次生成新的 Dictionary/Array。
- 预期结果：热路径应避免不必要的每帧分配。
- 修复建议：仅在健康、弹药、占点进度变化时发送状态增量，或复用预分配的缓冲区。

**P2-6 Godot 友军曳光与敌军同色**
- 文件：`godot/scripts/main.gd:196`
- 问题：`enemy_fired` 信号带 `team`，但 `main.gd` 对蓝方友军与红方敌军使用同一橙红色曳光。
- 预期结果：蓝方友军曳光应为蓝色系，红方敌军为红/橙色系。
- 修复建议：按 `team` 选择 tracer 颜色。

**P2-7 Godot 命中特效法线固定向上**
- 文件：`godot/scripts/main.gd:190`、`godot/scripts/gameplay/projectiles.gd:4`
- 问题：`_on_hit_target` 固定调用 `_fx.impact(point, Vector3.UP)`，墙面、斜面、掩体上的弹孔方向错误。
- 预期结果：弹孔应沿命中面法线生成。
- 修复建议：`hit_target` 信号增加 normal 参数，或由 `main.gd` 用命中点反查法线后传入。

**P2-8 Godot 任务目标文字中英混用**
- 文件：`godot/scripts/main.gd:30`、`godot/scripts/game/game_mode.gd:73`
- 问题：初始目标为中文，首帧即被 `game_mode.gd` 的英文目标覆盖，HUD 出现中英混排。
- 预期结果：目标文案语言统一。
- 修复建议：统一改为中文或英文单一语言。

**P2-9 Godot DMR 枪声未独立映射**
- 文件：`godot/scripts/audio/audio_manager.gd:31`
- 问题：`play_shot` 只区分狙击与 SMG 分支，`dmr` 落入默认突击步枪音色，三把武器听感区分不足。
- 预期结果：DMR 应有独立低音/延迟音色。
- 修复建议：为 `dmr`/`marksman` 增加独立音色变体。

## 5. 环境限制说明

- Godot 根证书读取错误与本机系统证书环境相关，非项目代码问题。
- Godot 退出时 `8 ObjectDB instances were leaked` 属于退出收尾警告，冒烟测试已确认无运行时脚本错误。

- Playwright 未安装，按任务要求未联网安装、未执行浏览器冒烟；Web 版仅完成构建验证与静态审查。
- 未进行中端桌面 60 FPS 性能实测；P2-3/P2-5 的热路径分配问题为静态判断，需性能测试确认实际影响。
