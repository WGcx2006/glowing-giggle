# 视觉审查标准

严格视觉审查子智能体按以下标准打分，满分 60，48 分以下必须返工，54 分以上才允许进入盲测。

## 评分项

1. 构图与镜头语言：主视觉是否有电影感，画面层次是否分明。（0-10）
2. 光照与体积感：阳光/天光/雾/云层是否真实，阴影是否柔和可信。（0-10）
3. 材质与贴图细节：混凝土、金属、植被、战损细节是否经得起近看。（0-10）
4. 后处理与色彩：SSAO/Bloom/色调映射/暗角是否克制且高级。（0-10）
5. 场景丰富度与叙事：战场是否像真实战区，有无可读的战争故事。（0-10）
6. 技术完整性：无穿帮、无悬浮、无闪烁、无死黑/过曝，帧率稳定。（0-10）

## 硬性门槛

- 不得出现纯色地面、空荡荡的中景、无阴影的场景。
- 不得出现明显的 z-fighting、闪烁粒子、错位贴花。
- 主视觉截图必须包含天空、中景建筑/车辆、近景掩体三层。
- 后处理必须明显提升画面，而不是让画面变灰或发糊。

## 返工流程

审查子智能体发现任意硬性门槛问题或单项低于 6 分时，必须列出具体文件与缺陷，指派实现子智能体修改后重新截图，再审查。直到全部通过。
