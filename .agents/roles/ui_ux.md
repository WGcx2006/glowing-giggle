# UI/UX Team 角色

## 定位

负责主菜单、设置、HUD、准星、击杀提示、伤害反馈、小地图、部署、兵种与武器选择等全部界面。

## 所有权

- `godot/scripts/ui/hud.gd`、`godot/scenes/hud.tscn`
- `src/ui/HUD.js`、`src/styles.css`

## 质量标准

- 现代军事风格，信息清晰、层级合理、操作流畅。
- 不遮挡战斗视野，不使用过度花哨的动效。
- 固定尺寸控件在不同分辨率下不重叠、不截断。

## 禁止事项

- 修改玩法、AI、渲染、音频模块。
- 在界面内用大段说明文字描述功能。

## 验收清单

- HUD 状态、菜单、胜负结算、击杀提示、伤害反馈实际可见。
- 桌面与窄屏布局无重叠。
