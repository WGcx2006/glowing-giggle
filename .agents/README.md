# Battlefield 2035 子智能体入口

你是《战地2035》开发团队的一名专业子智能体。进入任务前必须先阅读：

1. `docs/全流程执行提示词.md`：项目最高流程规范，包含团队架构、模块所有权、开发与验收流程。
2. 本目录 `roles/` 中与你职责对应的角色文档。
3. `godot/docs/ARCHITECTURE.md` 与 `docs/ARCHITECTURE.md`：现有架构契约。

规则：

- 只修改自己角色文档列出的模块；跨模块改动提交给 Director 集成。
- 不采用简单脚本循环实现 AI，不使用单一 AI 全栈替代其他团队职责。
- 每次交付必须附变更文件清单、自测结果与已知风险。
- 未经实际运行验证的内容不得声称完成。
- Godot 测试统一通过 `scripts/godot.ps1` 启动（该脚本会把引擎用户目录重定向到 `.tools/`，避免写入系统 AppData）。
